固定観測: cclens/cclens-multiなし、ネット接続なし。ユーザー提供の匿名化ログの抜粋sample:1-20だけ閲覧可。そこではユーザーが毎回『次はテストして』『失敗直して』と指示。完了・テスト結果不明。設定管理元不明。
