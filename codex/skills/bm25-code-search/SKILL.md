# BM25 Code Search

大規模または未知のリポジトリでコード探索を始めるときに使う。固定行数のコード断片をBM25で順位付けし、関連候補を先に絞る。記事の検証値（トークン30%削減）はこの環境で未検証なので、効果を断定しない。

## 実行

リポジトリのルートで、検索語を短い自然言語または識別子で指定する。

```bash
python3 ~/.codex/skills/bm25-code-search/scripts/bm25_search.py \
  "review gate repository" . \
  --top-k 8 --chunk-lines 40 --snippet-lines 8
```

出力は `path:start-end` と短いコード断片なので、上位候補から `Read` で必要な範囲だけ確認する。その後、正確な参照や漏れの確認に `rg` を使う。

## 使い分け

- 大規模・未知のコードベース: BM25で候補を絞ってから読む。
- 小規模リポジトリ、完全一致する識別子、設定キーの確認: 直接 `rg` を使う。
- 候補が空: 検索語を識別子・ドメイン語へ分解して再検索する。BM25の失敗を機能不存在とは断定しない。
- 編集前: BM25の出力だけで判断せず、候補ファイルの実装と呼び出し元を読む。

## 安全境界

スクリプトは`.git`、生成物、バイナリ、`.env*`、秘密鍵・証明書を除外する。検索結果に秘密情報が出た場合は出力を共有せず、検索を止めて対象ファイルを確認する。スクリプトはファイルを変更せず、ネットワークにも接続しない。
