# ワークフロー改善の試行記録

生ログは貼らず、参照先を使う。未取得は「不明」、未確認は「未確認」と記す。

- 対象: project / runtime / model / 期間 / 対象タスクの選定条件
- coverage: 入力元、取得範囲、欠測、collector の version
- 観測: 元ログ path:行 または event ID、成果物の参照、発言主体（人間 / 委譲 / 自動 / 不明）と件数の除外・不明
- 現状照合: 現在の分類、SSOT・修正時点・配布状況、修正後の再現または実利用の証拠（未取得は不明）
- 原因仮説: 別の説明と棄却条件
- 外部の実践: 一次資料 URL、revision または確認日、発動条件、適合 / 不適合の理由（未取得なら未確認）
- 今回の1変更: 起動条件、対象 SSOT、変更前後の差分、権限・依存、ユーザーの新たな負担
- 評価契約: 固定シナリオ、hold-out、比較条件、品質の合格条件、人間の介入・手戻り・時間・利用量の観測方法
- 撤回: 悪化と判断する条件、自分の差分だけを戻す方法
- 結果: 旧 / 新それぞれの観測、シミュレーションか実利用か、比較を妨げる条件差
- 判断: 採用 / 撤回 / 保留、理由、次回確認する scope と不足する入力
